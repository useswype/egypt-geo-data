# Contributing

Everyone is welcome to propose changes and contribute to this project. Thank you for helping keep data accurate and useful.

## Ways to help

- Report missing locations, incorrect names, or duplicate entries.
- Suggest corrections to Arabic names or English transliterations.
- Fix incorrect links between areas and governorates.
- Improve the documentation or propose other improvements.

## Propose a change

Open a GitHub issue describing your suggestion. For data corrections, include the affected entry, the proposed change, and a reliable source when available. You do not need to write code or submit a pull request to contribute.

If you are unsure about a change, an issue is a good place to discuss it first.
